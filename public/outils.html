Ma recette en 4 étapes

  • S'inspirer avec Godly, Mobbin ou Component Gallery (A).
  • Cadrer avec un DESIGN.md et Context7 pour que l'agent reste cohérent (A + B).
  • Construire avec Claude Code ou Blink.new, sur shadcn/ui et Magic UI (B + A + C).
  • Vérifier et publier avec Playwright MCP, Prbl, Sentry, puis GitHub → Cloudflare (B + C).

✂️ Grand ménage

La liste principale est passée de 156 à 40 outils le 18 sept. 2026, puis à 43 avec Delta et Prbl. Les produits arrêtés, archivés ou fermés aux nouveaux utilisateurs ont été écartés.

🚫 Accès retirés

Gemini CLI : l'accès par abonnement grand public a été retiré le 18 juin 2026 (clé API ou Vertex uniquement). Firebase Studio est fermé aux nouveaux comptes depuis le 22 juin 2026. Cody ne garde que son offre Enterprise.

🪦 Arrêts et renommages

GitHub Spark est arrêté depuis le 31 août 2026. Windsurf est devenu Devin Desktop. Supermaven et les plugins Amazon Q sont en fin de vie. Roo Code, Void et E2B MCP sont archivés.

💳 Gratuit, bêta, licences

Delta est gratuit pendant sa bêta. Prbl : le scan est gratuit, le correcteur est payant. Agent QA et Sentry MCP sont sous licence FSL (source disponible, pas open source au sens strict).
