🤔 Poste local ou full web : quel workflow pour quel projet ?

🖥️ Poste local : éditeur, Node et terminal sur ton ordinateur, puis GitHub. 🌐 Full web : Claude Code en ligne (ordinateur, mobile ou tablette), GitHub pour le code, Cloudflare ou Netlify pour l'aperçu et la mise en ligne. Rien à installer.

Type de projetWorkflow conseillé
Site vitrine, landing page, blog, prototype🌐 Full web
App web simple avec Supabase (comptes, données)🌐 Full web
Temps réel, multijoueur (Cloudflare Durable Objects)🌐 Full web (Cloudflare)
Depuis un mobile ou une tablette, sans ordinateur🌐 Full web
IA locale (Ollama, LM Studio), confidentialité totale🖥️ Poste local
Outils lourds ou qui tournent chez toi (Foundry, Hardhat, ROS, Arduino, Home Assistant, apps Apple)🖥️ Poste local
Gros projet, services à lancer ou déboguer en local🖥️ Poste local
